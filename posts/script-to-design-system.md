내 레포엔 파일이 딱 하나 있었어. 맥에 Whisper 까는 `setup-whisper.sh`. CSS도 없고 로고도 없어. 근데 이걸로 블로그랑 썸네일에 쓸 디자인 시스템을 만들었어.

## 스크립트에 이미 스타일이 있었어

다시 읽어보니까 규칙이 꽤 뚜렷했어.

- 진행 줄은 전부 `▶`로 시작해.
- 이미 깔린 건 건너뛰고 "이미 있음"이라고 말해.
- 오래 걸리는 건 크기를 괄호로 적어. `(~550MB)`처럼.
- 섹션은 `===== 설치된 버전 =====`으로 나눠.
- 마지막은 "설치 끝!" 한마디.

말투는 반말에 짧아. 이게 그냥 내 말투야. 그래서 이걸 그대로 규칙으로 옮겼어.

## 화면 값은 새로 정했어

색이나 글꼴은 스크립트에 없으니까 새로 골랐어.

| 항목 | 정한 것 |
| --- | --- |
| 대표색 | 핑크 하나. ▶ 마커랑 링크에만 |
| 상태색 | 완료 초록, 주의 주황, 실패 빨강 |
| 글꼴 | 설명은 IBM Plex Sans KR, 명령어는 IBM Plex Mono |
| 테마 | 라이트, 다크 둘 다 |

글자색은 두 테마 다 바닥 대비 4.5:1 넘게 맞췄어.

## 이제 이렇게 써

글은 마크다운으로 쓰고 명령 하나 돌리면 끝이야.

```bash
npm run post -- posts/script-to-design-system.md
```

```terminal post.mjs
▶ 글 만들었어: out/script-to-design-system/index.html
▶ 대표 이미지 만드는 중 (1200×630)
▶ 끝! out/script-to-design-system/cover.png
```

지금 보는 이 글도 이렇게 만든 거야. 위에 터미널 블록도 마크다운에 `▶` 줄만 적은 거고.

인스타용 이미지도 같은 스타일로 뽑아.

```bash
npm run image -- --type steps --title "설치 순서" --steps "Homebrew 이미 있음|모델 받는 중 (~550MB)|설치 끝!" --size square
```

## 해보니까

- 디자인 시스템 시작점이 꼭 디자인 파일일 필요는 없어. 평소 말투나 출력 형식도 충분해.
- 규칙이 내 말투에서 나와서 글 쓸 때 고민이 줄었어.
- 다음엔 카드뉴스 여러 장 한 번에 뽑는 것도 붙여볼 거야.
