맥시코시 미카 프로 에코 아이사이즈 보고 있어서, 사기 전에 사양이랑 테스트 결과를 정리해봤어. 직접 써본 후기는 아니고, 공식 사양이랑 해외 안전 테스트 자료 기준이야.

## 한 줄로

신생아부터 4살쯤까지 쓰는 360도 회전형 카시트야. ISOFIX 베이스에 고정하고, 뒤보기로 시작해서 크면 앞보기로 돌려.

## 사양

| 항목 | 내용 |
| --- | --- |
| 쓸 수 있는 아이 | 키 40~105cm, 18kg 이하 (대략 0~4살) |
| 앞보기 | 15개월 넘고 키 76cm 이상부터 |
| 회전 | 한 손으로 360도 |
| 설치 | ISOFIX 베이스 + 바닥 지지대 |
| 무게 | 약 14.5~14.7kg |
| 안전 테스트 | ADAC 2022 good (2.1), ANWB "좋음" |

## 좋은 점

- 회전돼서 태우고 내리기 편해. 문 쪽으로 돌려서 앉히면 돼.
- 어깨 벨트가 위로 걸쳐져 있어서 아이 앉힐 때 안 걸려.
- 바구니 카시트 없이 처음부터 이거 하나로 가도 돼.

## 아쉬운 점

- ISOFIX 없는 차엔 못 써. 차 안전벨트로는 설치가 안 돼.
- 15kg 가까이 돼서 차 두 대 오가며 쓰기엔 무거워.
- 105cm까지라서 그다음엔 주니어 카시트를 따로 사야 돼.
- 조수석에서 뒤보기로 쓰려면 에어백을 꺼야 돼.

## 사기 전에 확인할 거

```terminal 체크리스트
▶ 우리 차 ISOFIX 있는지 확인
▶ 맥시코시 차량 호환 목록에서 차종 확인
! 비슷한 이름 "미카 360 프로"랑 헷갈리지 마
▶ 조수석에 달 거면 에어백 끌 수 있는지 확인
▶ 확인 끝!
```
